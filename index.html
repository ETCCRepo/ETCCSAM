📖 ETCC Silent Auction Manager — User Manual

      

        
        
      

    

    

      
SAM manages the full silent auction lifecycle for the East Tennessee Corvette Club — from item intake through payment, pickup, and post-auction follow-up. Work through the seven numbered steps in order for each auction event. Print Invoices, Configuration, and Settings are supporting tools available any time from the left navigation.


      
Step 1 — Donated Items

      
Use + Add Item to enter each donated item — category, description, value, reserve, and donor details — directly into the database. Each item is assigned a unique number based on its category (e.g. 200-3 for the third Corvette item). The Source column shows whether each item was manually Added or later Edited.


      
Step 2 — Create Bid Sheets

      
Generates a printable bid sheet for each item. Each sheet shows the item number, description, donor, value, starting bid, and a numbered table of bid rows with increment amounts. Starting bid percentage and bid count are configurable in Settings. Select individual items or use the header Select-All checkbox, then click Print.


      
Step 3 — Registrations

      
Shows registered bidders. The table auto-populates from the configured API URL (see Developer > API) every time this screen is displayed, replacing whatever was there before. Each record stores a Reg Number, name, email, and phone.


      
Step 4 — Record Winning Bidders

      
After the auction closes, enter the winning bidder number and winning bid amount for each item. Type the bidder number and bid amount into each row — entries are saved immediately as you complete each field. Only rows with both a bidder number and a bid amount are recorded as winners.


      
Step 5 — Announce Winners

      
Displays a table of all bidders who won one or more items. Use this screen to publicly announce winners at the event.


      
Step 6 — Pay & Pickup

      
Records payment method and item pickup status for each winning bidder. Supports Cash, Check, Credit Card, and Other. Credit card totals automatically include the Square transaction fee (configurable in Settings). Mark each bidder as paid as they are processed.


      
Step 7 — Post Auction

      
Reporting and email tools for after the auction closes.

      
Reports (each opens a printable view):

      
    
        
  • Auction Summary — bidders, items, winners, and total income
    • 
        
  • Winning Bidder — each winner's items and amount due
    • 
        
  • Donor Report — items donated and income per donor
    • 
        
  • Club Financial Summary — income broken down by payment method
    • 
        
  • Items Not Paid — won items without payment received
    • 
        
  • Items Not Won — items with no winning bid, with donor info
    • 
      

      
Email tools (see Email Tools below):

      
    
        
  • Thank You Email — send thank-you / winner emails to selected bidders
    • 
        
  • Winning Bidder Pickup — send pickup instructions and an invoice to winners
    • 
        
  • Item Donation Pickup — tell donors of unsold items to pick them up
    • 
      


      
Print Invoices

      
A standalone tool for generating printed invoices for winning bidders. Select bidders using the checkboxes (or the header Select-All), then click Print. Each invoice lists the bidder's winning items, amounts, total, and payment options including the credit card surcharge based on the Square fee settings.


      
Email Tools

      
Each email tool on the Post Auction screen opens a Select modal listing the relevant recipients with checkboxes. Choose recipients, click Preview to review a branded email for each one, then click Email to send via the Gmail API. If you are not already signed in to Gmail, a sign-in window opens automatically. Emails are sent as branded HTML with the club logo and a three-column footer; email addresses in the body become clickable links.

      
    
        
  • Thank You Email — lists every bidder. Winners receive the Winning Bidder template with the items they won and amounts; non-winners receive the Thank You template.
    • 
        
  • Winning Bidder Pickup — lists winners who have not yet paid. Each email embeds the full Silent Auction Invoice (items, Cash/Check Due, and Credit Card Due including the Square surcharge).
    • 
        
  • Item Donation Pickup — lists donors whose items received no winning bid, grouped by donor. Each email uses the Donor Item Not Bid On template and lists that donor's unsold items to pick up. Donors with no email on file are skipped.
    • 
      

      
The wording for all of these (subject, body, and footer) is set on the Configuration screen.


      
Configuration

      
Password-protected screen for club identity and email wording:

      
    
        
  • Club Branding — club name, short name, logo, and favicon (applied throughout the app and in emails)
    • 
        
  • Auction Location — venue name and address
    • 
        
  • Email Templates — Subject, Body, and a three-column Footer for each of: Thank You, Winning Bidder, Winning Bidder Pickup, and Donor Item Not Bid On. Type a bare email address in the body and it becomes a clickable link automatically.
    • 
      


      
Settings

      
Password-protected. Key options:

      
    
        
  • Gmail OAuth Client ID and Inbox Email — required for scanning the inbox and sending emails
    • 
        
  • Starting Bid % — starting bid as a percentage of item value (default 30%)
    • 
        
  • Final Bid % — highest bid row as a percentage of item value (default 150%)
    • 
        
  • Bid Count — number of bid rows on each bid sheet (default 25)
    • 
        
  • Walk-in Start — first bidder number assigned to walk-in registrations (default 1000)
    • 
        
  • Square Fee % and Square Flat Fee — credit card surcharge rates used on invoices and Pay & Pickup
    • 
        
  • Settings Password — controls access to Settings, Configuration, and Delete Auction
    • 
        
  • Maintenance Mode — shows visitors a maintenance screen; staff bypass it with the settings password
    • 
        
  • Developer Tools — debug mode, maintenance mode, environment, debug log, database push
    • 
      


      
Data & Sync

      
All data is stored in the browser's localStorage and automatically synced to a MySQL database on the server after every change. On startup, the app loads the latest data from the server so data is preserved across browsers and devices. Use the Backups card in Settings to save a dated snapshot of the live database on the server, view the backup log, or set up an automatic daily backup.
